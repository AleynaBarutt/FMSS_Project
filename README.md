# Mobile Car Rental Application - Project and Test Automation

This project involves a comprehensive analysis and test automation for the development of a mobile car rental application, aligned with the entry plans of a prestigious holding into the car rental sector.

## 📁 **Project Content**

### 1. Benchmarking (Market Research)

Local and global leading mobile car rental applications were analyzed. As a result of this analysis, key features in areas such as customer experience, security, and user-friendly interfaces were identified. Features that will differentiate our company in this market were determined and presented.

### 2. Scope and Core Features

Considering time and budget constraints, 10 core features to be included in the application and 5 additional enhancements for future development were identified. These features were prioritized, and the project scope was defined accordingly.

###  3. Backlog Management (MVP and Tasks)

The project was planned in three separate MVPs (Minimum Viable Products). For each MVP, the 10 most critical backlog items were identified, and each item was assigned at least two tasks. Workloads were balanced across the MVPs.

### 4. Time Management

The project is planned to be completed within a 9-month period, from September 2024 to June 2025. Timelines for each MVP and critical milestones were detailed in a schedule.

### 5. Use Case Methodology

The project details were structured with 50 requirements. These requirements were prepared using the Use Case Methodology to answer the Who-Why-What questions, ensuring the functionality and alignment with user needs.

### 6. UML Diagrams

UML diagrams were created to visualize the general workflow and relationships between components of the application. These diagrams support the development process and enhance customer understanding.

### 7. Mock-Up and UI/UX Prototypes

User-friendly interface mock-ups for LOGIN, LOGOUT, and SIGNUP processes were prepared following UI/UX principles. These prototypes were designed using tools such as JustInMind and Balsamiq.

### 8. Analysis Document and Database Management

An analysis document was created for the SIGN UP process. This document included data headings, data types, and foreign keys required for the database. Additionally, alternative solutions for managing potential changes in the tables were discussed.

### 9. Demo

A demo showcasing the LOGIN, LOGOUT, and SIGNUP processes of the application was developed. This demo was used to demonstrate the application's functionality to the client.

### 10. Migration and API Application

An action plan was created for transitioning the existing 50,000 customer base from another application to the new application. Additionally, solutions were developed for validating customers' driver’s license information through the General Directorate of Security's system.

### 11. KVKK Compliance and Security

Various security alternatives were explored to limit access to customer data and ensure no traces are left in the production environment in compliance with KVKK regulations. These alternatives included assigning person-based access permissions and implementing logging practices.

### 12. Data Mining and SQL Usage

From the registered customer database, the number of customers aged 20-22 who registered in June was extracted. This data mining operation was conducted using SQL queries and was utilized in the analysis processes of the application.

## 🛠 **Test Automation**

Test scenarios developed within the project were written using Cucumber. These tests were prepared to ensure the accuracy and reliability of critical processes in the application. Additionally, these scenarios were successfully executed on the demo screen.
